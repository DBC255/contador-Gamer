# 🎮 Contador Gamer

Projeto desenvolvido em React NATIVE com Expo.



# preview do APP

O aplicativo possui:
* contador de pontos;
* botão de almentar;
* botão de diminuir;
* botão de resetar;
* interface estilo gamer;

---

# Tecnologias utilizadas

* React Native
* Expo
* JavaScript

---

# como executar o projeto

## 1. clonae o repositorio
```
git clone https://github.com/DBC255/contador-Gamer.git
```

## 2. entrar na pasta do projeto
```
cd contadorGamer
```

## 3. Instalar dependencias
```
npm install
```

## 4. Rodar o projeto
```
npm start
```
